## 内容与语言规则

活动事实锁定为 **LALM 项目资料交流展**，2026.11.19–11.21，丄美术馆。15 组项目与艺术家仍按既定机构拉丁名称 A–Z 排序，并以稳定记录绑定；不能因目标文字、音译形式或国籍改变次序与身份。

本轮新指示覆盖此前“只做标题拟音、其他信息沿用中英文”的做法：

- 中文版以中文为主，英文为辅助；使用真实不同的中文字体性格，而非同一黑体的缩放、描边和换色。
- 英文版的展名、栏目、角色、时间地点说明与名单均以英文组织，中文最多作为小型身份锚点。
- 日文、韩文、印地语版对整页信息进行目标语言呈现，包括普通说明、角色、地点及名单。主标题“我们知道”采用该语言的自然含义表达，不再把 We Know 的读音转写当作主题翻译。
- 人名、机构名和地名保持同一身份。已有确认名称优先；必须新增目标文字时按读音转写，不按姓名或机构的字面意思另起名字。原始中文与拉丁身份形式保存在内容数据中，必要时可以小字辅助。
- 日期、时段、观察员空位、15 组配对、主办协办关系和五份原始 logo 不变。

结构化本地化内容见 `content/localizations.json`；锁定原始身份见 `content/content.json`、`content/final-layout.json`。普通说明翻译与专名音译是两种不同处理。

新增写法属于机器翻译／音译，**待参与者／母语核对**；字形和排版检查不代表正式名称已获本人认可。印地语是用户指定的设计语言，不据此推断艺术家的母语。核验边界保存在文档，不渲染进海报或画廊界面。

## 画廊界面

首页只以中文、英语、日语、韩语、印地语、法语、西班牙语、德语、阿拉伯语、葡萄牙语写“我们知道”，保留问号。没有介绍性文案。

手机、桌面都一行一张海报，按视口高度控制展示尺度，长列表浏览。每张仅保留必要编号、语言及下载控件，不显示人为方案名、概念介绍、参考分析或制作状态。可按语言筛选，打开单张后前后切换，支持左右键与 Esc。

## 文件

- `previews/`：轻量网页预览；ORIGINAL 保留原 GIF。
- `print/`：26 张新稿的全尺寸 PNG；ORIGINAL 保留真实静态原稿规格。
- `sources/`：真实 SVG 图形与字体轮廓，不是改后缀的扁平图片。
- `design/render.py`：可维护排版逻辑；`design/*.text.json`：实际排入文本、字体与位置记录。
- `content/`：锁定身份、本地化词句、音译对应与语言审计。
- `assets/`：委托者提供的五份品牌图像。
- `fonts/`：实际使用的开放字体／项目子集及完整许可。
- `research/references.json`：参考来源与观察；不公开参考原图。
- `qa/`：各轮独立检查记录；历史检查不能充当本轮新图验收。
- `downloads/`：与本轮最终成品一致的高清合集和源文件资料包。

## 字体与复现

中文题字在宋体、文楷、毛笔楷书、楔形宋体、圆角窄体和无衬线之间区分；正文也按方案选择宋体、文楷或无衬线，保持可读层级。字体来源、真实字重和覆盖范围见 `fonts/NEW-FONTS-README.md`、`fonts/NEW-FONT-SOURCES.json`。马善政等字体是作者已有字体，不声称本项目原创手写。

Python 3.11+：`pip install pillow fonttools uharfbuzz`

Node 20+：`npm install`

运行 `python design/render.py` 生成 SVG；运行 `node design/export.cjs` 生成网页预览；运行 `node design/export.cjs --print` 从 SVG 直接生成全尺寸 PNG。具体参数以脚本为准。

目标规格为竖版 60×90 cm，7087×10630 px、300 PPI、sRGB；新稿从矢量源直接光栅化，不能把小尺寸预览插值当高清。印地语对整串文字用 HarfBuzz 塑形，之后转真实轮廓。日文、韩文使用对应区域字形；字体回退不能丢失重音或附标。

原定稿是 1200×1800 PNG 和 800×1200 GIF，不冒充 300 PPI 印刷稿。PNG 也不是已经完成 CMYK、出血和纸张打样的印厂生产文件。

`design/hands.png` 与 `design/paper.png` 为本项目生成的摄影式意象，不是活动纪实照片；图形中有意采用矢量网点，不宣称具有原图中不存在的摄影细节。
