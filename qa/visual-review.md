# 26 款小样独立视觉检查

检查日期：2026-11-10。检查者：references 子任务，未参与海报渲染代码编写。
实际查看：design/contact-0.jpg、contact-1.jpg、contact-2.jpg；另打开 previews/ZH05.jpg 与 previews/EN05.jpg 检查同构问题。此文件是小样的设计审查，不是母语审校或印刷验收；完整文字和像素尺寸须由另一次工程检查验证。

## 判断

已出现几类明显不同的观看路径：文字关系网、竖向受压字、遮挡图像、折页、核心符号、轻线条、满版负形文字、低密度单一干预。它们有可辨识差异。

但是当前小样尚不能整体宣称通过“任意两款至少 4/8 项有实质区别”的验收。部分方向仍共用相同骨架，只换题字、颜色和少量装饰。最需要处理的是 EN05 / ZH05、EN06 / EN10、ZH02 / ZH09；其次是 JA01 / ZH04 / EN02 的侧栏＋高纵题结构。参考台账不是差异已经成立的证据。

## 优先返工

### 1. EN05 与 ZH05：明确同构，必须改一款

共同骨架：顶部一条大标题；其下同样位置的左活动信息＋中项目＋右参会者；中下段大面积空白；同样宽度的 logo 横条；最底端年号或 LALM / 2026。当前差异主要是衬线/黑体、绿/酒红、横线/圆点。没有形成登记簿与档案之间实质不同的阅读逻辑。

建议改 EN05：保留票据命题，采用一条连续的窄卷轴登记主列；名单按编号与人名的绑定记录流经长条，活动信息变为票据头、时间戳与末尾凭证，标题跨接票据切口。这样同时改变骨架、信息组织、密度和观看路径，而非只加更多打孔圆点。

### 2. EN06 与 EN10：对角色块模板复用明显

共同骨架：左上窄信息块，右下名单块，主标题在右上，图形填左下或中央。EN06 的斜线与 EN10 的横向信号不足以使整体独立。

建议改 EN10：建立完整横向播报带，标题和静默区按时间轴分段，名单做与时间轴平行的底部连续行或分节列；把信息区从左上/右下两个矩形撤出。保留“中断”而不是增加随机故障噪点。

### 3. ZH02 与 ZH09：同一网点图像＋下部信息结构

两款都是上部约三分之二网点图像，中文标题贴图像下缘，下部三列信息和底端 logo。虽然图像内容不同，但媒介、密度与阅读路径过近。

建议改 ZH09：微观纸纤维沿狭长测量带贯穿版面，不再做横向图片框；刻度和标题沿材料边界组织，名单进入独立侧列或中部开口，保留大面积冰蓝负空间。改变裁切、图像占比、信息区位置与文字作用。

### 4. JA01、ZH04、EN02：需要至少重构其中一款

都有左边窄资料列、右边巨大的竖向标题对象。EN02 的超窄拉丁字有独立力度，ZH04 层叠材料机制可保留；JA01 更接近把其他大字替换为纵排假名。

建议改 JA01：用两条相距很远但共同组成完整语句的日文纵列，让空白本身成为主角；信息采用底部横向短列或上下角的非连续分布，避免再次把全部资料挤进左侧长栏。长音符修正之外，还需要结构性变化。

## 推荐保留并继续打磨的 5 款

1. ZH06：回声轨迹与最后稳定标题有清楚的“散开—聚合”阅读关系，区别于矩形框内的字和图。注意回声尾端不能淡到不可辨。
2. EN03：先读上部信息，再被遮挡横条引向人体图像；“看见／被挡住”直接关联主题。维持必要信息无遮挡。
3. EN07：一个原创开口符号作为强焦点，题字和下部信息有明确层级。检查符号是否过像通用电源标识，并通过开口/内部形态进一步独立化。
4. ZH10：低密度、小标题和细长折口形成迟疑的观看动作，是这一批里最明显的留白方向。不要因为显得空而随意加元素。
5. KO01：完整韩文字块可以承载模块关系，目前上下块状标题与中央信息带有很强的节奏。仍需语言确认，且上下两组标题应有不同空间功能，避免只是重复两遍。
